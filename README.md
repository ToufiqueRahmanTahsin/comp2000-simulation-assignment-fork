# COMP2000 Simulation Assignment
A rudimentary simulator that showcases an ant colony foraging for food. The simulation features three types of ants: Scouts, which explore the map and discover food sources; Foragers, which follow pheromone trails to locate food and transport it back to the nest; and Soldiers, which patrol the environment and leave pheromone trails. Ants use different movement strategies, while pheromone trails gradually decay over time.
